 학교 게시판 작성 내용
====================================================

■ 제목:
"Django + Render로 개인 블로그 웹서비스 배포하기"

----------------------------------------------------

■ 프로젝트 개요
Python Django 프레임워크를 사용하여 블로그 웹서비스를
개발하고 Render 클라우드 서버에 배포하였습니다.

■ 사용 기술
- Backend: Python, Django 6.0.3
- Database: SQLite (로컬), Render 내장 DB (배포)
- 배포: Render (무료 클라우드 서버)
- 버전관리: Git, GitHub

■ 구현 기능
- 게시글 작성 / 수정 / 삭제
- 카테고리 / 태그 분류
- 댓글 기능
- 검색 기능
- 로그인 / 로그아웃
- 관리자 페이지
- Bootstrap 5 반응형 UI

■ 배포 주소
https://django-blog-16zr.onrender.com

■ 소스코드 (GitHub)
https://github.com/hellodm7-svg/django-blog

====================================================
 캡처해야 할 화면
====================================================

1. 블로그 메인 화면
   → https://django-blog-16zr.onrender.com 접속 후 캡처

2. 게시글 상세 화면
   → 관리자 계정 만든 후 글 작성 → 상세 화면 캡처

3. 깃허브 저장소 화면
   → https://github.com/hellodm7-svg/django-blog 접속 후 캡처

4. Render 배포 완료 화면 (Live 표시)
   → https://dashboard.render.com 접속 → django-blog 클릭 → Events 화면 캡처
