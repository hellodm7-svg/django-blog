[사용자] venv 가 뭐야

[AI] venv는 Python의 가상환경(Virtual Environment)입니다.
- PC에 Python 프로젝트가 여러 개 있을 때, 각 프로젝트마다
  독립된 패키지 공간을 만들어주는 도구
- 프로젝트마다 다른 버전의 패키지를 충돌 없이 사용 가능
- 기본 사용법:
  python -m venv venv         (가상환경 만들기)
  venv\Scripts\Activate.ps1  (활성화, Windows)
  pip install django           (패키지 설치)
  deactivate                   (비활성화)
